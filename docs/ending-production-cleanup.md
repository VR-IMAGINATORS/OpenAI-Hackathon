# エンディング制作で使うもの・撤去したもの

2026-09-13。検証用の仕組みが別セッションの制作へ混ざらないよう、実行ツールと参照先を整理した。

## 現行の流れ

履歴と確定結果 → 人物の目的と場面を選ぶ → 撮影・音・文字を文章で設計 → 開始画像1枚 → H3で本編・文字・VFXを同時生成 → 照合・登録・表示。

人物・道具の位置、支持、動き、カメラの方向は文章で考える。座標から空間を構築したり、配置図を生成したりする工程はない。

| 対象 | 整理結果 |
|---|---|
| staging.py、専用テスト、spatial-staging.md | 撤去。座標モデル・衝突チェック・配置図・時間プレビュー・プロンプトへの変換は使用しない |
| verify_and_concat.py | 撤去。動画連結・音量測定・フレーム抽出等の補助ツール。未使用なのにmedia.pyが存在を必須としていた依存も除去 |
| ending-video-handoff.md、ending-video-quality-design.md、ending-cinema-rewrite.md | 古い調査・設計候補の文書を撤去。Git履歴に保持し、リンク切れを解消 |
| ending-film-production-design.md、ending.md、Story.md | 現行の設計・実行手順・世界観/文体として保持。撤去したツールへの誘導を除去 |
| H3の撮影・文字演出・入力記法の調査 | ノウハウとして保持。一般のR2Vや2画像例はゲームの必須工程ではない |
| game.pyのffprobe検査 | 保持。通常の動画登録で実際に使う尺・寸法・音声streamの検査。内容品質の自動判定ではない |
| 終了画像ありの旧run照合 | 過去の承認済み動画の回収・登録互換性として保持。新規生成の標準ではない |
| runs内の動画・画像・比較試作・送信記録 | 保持。通常手順から呼び出さない過去の成果物であり、今回の削除対象に含めない |

エンディングの実行手順は[ending.md](../.agents/skills/call-to-past/references/ending.md)。検証・判断の過去の記録は当時の事実として残す。廃止したファイルへのリンクだけを撤去済み表記へ変更した。

## 確認

撤去後の会話版無課金テスト69件が成功。前回77件から減った8件は撤去した空間ツール専用テスト。隔離コピーでのH3送信・回収テストも、未使用QCツールなしで成功。実API送信・新規動画生成は行っていない。
