# 2026-09-12 AWS公開と複数人試遊への変更

判断主体: ユーザー。grill-me Q1〜Q16で合意し、最終確認で確定。
元資料: proposal/server-structure-change/server-structure-change.md。
反映先: specs/hosted-multiplayer/spec.md。技術詳細は同plan.mdで別途確認する。

## 背景
審査員はGitHubからローカル起動するのではなく、資料にあるURLから体験する。GitHubは実装確認用。APIキーをサーバーに保持する点は維持し、独立した認証リレーを必要とする前提を撤回する。

## 合意した選択
| 論点 | 決定 | 理由・代替案 |
| --- | --- | --- |
| 同時体験 | 各自独立、初期5人、設定変更可能、満員は再試行案内 | 一人占有・待機列は公開試遊に不向き/今回不要 |
| 永続化 | メモリのみ。再起動・更新後は案内して最初から | ハッカソン優先、DB復元は後続 |
| 認証 | 共通合言葉、アカウント・個別招待なし | URLと合言葉だけで配布 |
| 復帰 | 同じブラウザは復帰。切断猶予は最大60秒 | 短い撮影・通信トラブルに対応、枠の放置を防ぐ |
| 枠と寿命 | 音声接続開始操作で確保、チュートリアル含め最大10分 | ページ閲覧だけでは枠を使わない。再接続で期限を延長しない |
| 環境 | 当初は共用、審査前に別環境へ分離 | 審査用は確認済みバージョン、合言葉・枠を独立 |
| 配信 | 開発はmainマージで自動更新、審査は手動 | 更新時にプレイ中の人はほぼいない。更新による終了を許容 |
| AWS | Lightsail Containers Micro、各環境1台、標準HTTPS URL | 独自ドメイン不要。負荷実測後Nano縮小を検討 |
| 費用 | 小さく開始。基本料金1環境月10 USD、2環境月20 USD目安 | API・税・転送超過等は別。最安のみを優先せずMicroで検証 |
| 終了 | 期間終了後にリソース削除 | 無効化だけではLightsail課金が続く |
| ログ | 開始終了・エラー・処理時間・API回数のみ | 写真、会話本文、合言葉、キーを保存しない |
| 範囲 | サーバー統合、複数人、参加復帰、公開、デプロイ | ゲーム/プロンプト改善、動画等は別作業 |

## 影響範囲
apps/local-serverの単一GameSession・招待所有権を複数セッションへ変更。apps/relayのprovider通信/上限を同一プロセスの内部サービスへ移す。UI参加導線、tools/mobile.tsの招待QRと別管理ポート、設定例、README、AGENTS.mdの旧構成説明を実装時に更新する。旧仕様書は履歴として残し、本変更が公開/所有権/配信の前提を上書きする。

## 後続確認・再評価条件
同時5人の実性能、実音声終了、AWSデプロイ/再起動の挙動は未検証。メモリ不足ならサイズを再検討する。台数増加・途中再開保証が必要になれば外部状態管理を再設計する。秘密情報や実際のAWSアカウント値はこの文書へ転記しない。
