# Codex App Server ログインPoC

## 目的・スコープ
前回の2つのHTML資料のPhase 1を実装する。本人がOpenAIでログインし、本人のCodex利用枠でテキスト／任意の写真から構造化判断を1回取得できるか確認する。独立したローカルCLI。ゲーム・Live・画像生成・動画・公開HTTP・多人数は変更しない。

## 受け入れ条件
- R1: `npm run poc:codex` で専用App Serverをstdio起動。既存の.env、認証ファイルを読まず、APIキーを子プロセスへ継承しない。
- R2: device code（既定）または明示したbrowserログインを案内し、本人の操作後にaccount/readでChatGPT認証を確認。ログインだけのモードも提供する。
- R3: model/listで既定Lunaまたは明示モデルの提供を確認。勝手に高額モデルへ変更しない。普通利用の禁止や枠切れ時は推論しない。
- R4: 入力は短いテキストと任意の画像1枚。JSON Schemaで結果を要求し、成功turnの最終JSONだけ検証・表示。自動再試行・API fallbackなし。
- R5: 応答前の通知、分割JSON、プロセス終了、期限切れ、拒否・不正結果を扱う。中断後はワーカーを終了。認証・写真・履歴を終了時に廃棄する。
- R6: ログは工程・安全なエラーコード・モデル・利用量だけ。ログイン案内と判断結果は本人の端末にだけ表示。メール・トークン・上流生エラーを保存しない。
- R7: fakeによる無課金検証と、実ログイン／推論結果を区別して記録する。

## 制約
ローカル単独利用のPoCであり、OSユーザー間の隔離を提供しない。API同等の出力token上限は未確定。1回のturnでも本人の枠を消費する。普通利用の残量確認は追加費用ゼロを保証するものではない。通常のゲーム制約や本番サポートを満たしたと扱わない。
