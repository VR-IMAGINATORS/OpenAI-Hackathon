## 完了した確認
- TypeScript型検査、標準シナリオ検証、Web/サーバービルド。
- Nodeテスト54件成功: ゲーム時計、二重実行、失敗時非消費、判定中失効、写真再エンコード、所有権、認証、中継上限、強制切断。

## 再現コマンド
npm test / npm run build

ブラウザ検証は任意のPlaywright実行環境とインストール済みChromeを使用。Viteを127.0.0.1:5178で起動して、PLAYWRIGHT_MODULEにPlaywright moduleのパスを指定し node apps/web/tests/mobile-smoke.cjs。テスト用API/音声を使い実APIを呼ばない。使用環境ではCodex同梱Playwrightを利用した。スクリーンショットはGit除外のartifacts/に保存。
