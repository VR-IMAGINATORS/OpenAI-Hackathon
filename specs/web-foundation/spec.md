# Web版の開発基盤

2026-09-12。grill-me Q1〜Q32と「それで進めてください」に基づく最初の土台整備。

## 目的と範囲

写真と音声で伝える使い方をAIが理解し、未来の脱出を助けるゲームを4人日程度で開発する。そのためのREADME・指示書・設定・起動と通信の基盤を整える。
今回の完成範囲は**画面、ローカルサーバー、中継サーバー、モックによる通信確認**。GPT-Live音声、AI判定、画像・動画生成、実ゲーム進行と公開運用は後続実装。モック成功は実APIの成功を意味しない。
既存 .agents/skills/call-to-past/ と specs/call-to-past/ はドッグフーディング用の参考。Web版の仕様・承認・検証実績として流用しない。ゲーム全体の合意は [game-direction.md](game-direction.md)。

## 画面・HTTP・保存

接続画面はタイトル、未来との接続という導入、シナリオ名、設定値、合言葉入力、接続確認ボタン。常にモックの開発基盤だと示す。送信中の二重操作を防止し、認証無効時は入力不要。

GET /api/bootstrap は公開シナリオ概要と中継の公開状態。達成条件や未公開障害は返さない。
POST /api/connection は合言葉を受け、中継で認証し、トークンを使ったモック診断を返す。トークンはその要求内のみ使用しブラウザへ返さない。
API詳細は contracts/openapi.yaml、データ詳細は data-model.md を参照。

標準はloopback bind。ブラウザ要求はHost/Originを照合、OriginなしのテストCLIは許可。中継への通信はサーバー間、外部URLはHTTPS（HTTPはloopbackのみ）。サイズ上限/timeout/redirect拒否を設ける。
土台では写真・音声・プレイ履歴を取得/保存しない。認証情報はメモリのみ。上限は単一プロセス・再起動でリセットする開発用。既存ルート.envを自動読込しない。実APIキーはこの段階で一切使用しない。
