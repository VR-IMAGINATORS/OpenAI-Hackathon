# ハーネス改善の動作確認

既存の `.env.local` を使い、サーバーを再起動して新しいプレイを開始してください。進行中のプレイは開始時の設定を保持します。既存ファイルを `.env.local.example` で上書きする必要はありません。

- PC: `npm run dev` → `http://127.0.0.1:5173`。
- スマホ: `npm run play:mobile` → 表示されたHTTPSのQR。PCでも同じURLを使用できます。
- 外部AIなしの `npm run dev:all` では、本書の実音声確認はできません。

## 最初に確認する体験

| 操作 | 期待する動作 |
| --- | --- |
| 縄を切れる物が必要な状況でハサミの写真を送信し、追加で指示しない | 明らかな用途なら自分で使い、確定結果と状況画像が届く。次の障害を勝手に解かない |
| 用途が分からない物を送る | 必要な点だけ短く尋ねる。写真は受信時に消費される |
| 判定中に「やめて」または「待って」と伝える | 結果確定前に受信した依頼なら止まり、旧判定の成功や画像が後から出ない |
| 判定中に「違う、刃ではなく持ち手を使って」と訂正する | 前の処理を取り消し、実際の訂正を根拠として再判断する。訂正が曖昧なら止めて聞き直す |
| 判定中に同じ実行指示を繰り返す | 二重実行にならない |
| 具体的な危険を伴う使い方を依頼する | 損失や危険を説明して確認する。「それでやって」はその提案への同意として扱う。別の提案へ流用しない |
| 「それはハサミではなくカッター」と認識を訂正する | 同じ写真の認識が更新される。写真送信回数は戻らない |
| 「今どういう状況？」と尋ねる | 今見えている状況を説明する。未開示の真相や後の障害を言わない |
| 解法を聞かず会話する／ヒントを求める | 通常は解法を先回りしない。求めた際は現在開示できる情報だけで答える |
| 制限時間の残り60秒、15秒付近まで遊ぶ | 通常警告は会話の静寂を待つ。最終警告は最大3秒待ち、切替表現を伴って伝える |

取消しの境界は「サーバーが音声認識結果を受信してから、結果を確定するまで」です。すでに確定した結果は巻き戻しません。実際に声を出した瞬間に遡って取消す保証はありません。

## 音声で特に確認する点

PCのスピーカー・イヤホン、スマホでそれぞれ、息継ぎで警告が割り込まないか、同時発話で不自然に切れないかを確認します。タブを背景に移して戻す、再生がブロックされた状態から再開するケースも確認してください。音声活動は意味上の文末検出ではなく、静寂の推定です。

開発者ツールのNetworkでは `/api/play/voice-activity` が活動中に送信されます。本文は世代・連番・input/outputのactive/quiet/unknown・playbackReadyだけで、生音声や振幅はありません。unknownが長く続いた環境と再生状態を記録してください。通信成功やLiveコマンドのackは「聞こえた」ことを意味しません。

## 調整場所

- `config/game-core.json`: 日英の会話・導入、`acceptancePolicy`、`recovery`、`warnings`。通常60秒／最終15秒／最終待機3秒が初期設定。
- `scenarios/story-catalog.json`: 現在の世界・物理制約、`knowledge`、`observationTargets`。known/observable/hiddenと前提条件・開示方法を編集する。
- `apps/local-server/hosted-runtime.ts`: 写真・音声の統合、危険確認、取消し制御、確定結果の通知。
- `apps/local-server/game.ts`: 行動予約・確定、版照合、取消し、同じticketでの技術的再試行。
- `apps/local-server/harness-decisions.ts` / `core-intent-ai.ts`: 写真の自動使用、制御分類、会話からの判断。
- `apps/local-server/companion-knowledge.ts` / `companion-response.ts`: 開示条件と、公開情報だけを使う発話生成。
- `apps/local-server/voice-notifications.ts` / `apps/web/src/voice-activity.ts`: 警告待機・優先順位と音声活動の推定。

設定保存後に `npm run check` で全18構成を検証できます。クレジット管理・シナリオ生成の接続は今回の範囲外です。
