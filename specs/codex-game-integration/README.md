# Codexログインでローカル試遊

ローカルPCで配信するゲーム画面から、プレイヤー本人がログインして遊ぶ実験用構成です。起動端末でのログインは不要になりました。通常のAPI版も残っています。外部公開・同時複数人・スマホ接続・プレイヤーAPIキー入力UIは今回の対象外です。認証はブラウザセッションごとに独立しています。詳細は [プレイヤーログイン](../codex-player-login/README.md) を参照してください。

## 起動

既存の `.env.local` に音声・画像・動画用のAPI設定が必要です。ゲーム判断は `GAME_MODEL` のモデルをCodexで使います。先の単体PoCと同じLunaを試す場合、Git Bashでは次を実行します。

```bash
GAME_MODEL=gpt-5.6-luna npm run play:codex
```

PowerShellの場合:

```powershell
$env:GAME_MODEL = 'gpt-5.6-luna'
npm run play:codex
```

既存の判断モデル設定を使う場合は `npm run play:codex` だけで起動します。ビルドとcheckは自動で実行されます。モデルがプレイヤーのアカウントで利用できなければログイン状態を失敗とし、ゲーム開始を許可しません。

1. 起動後に `http://127.0.0.1:4310` をPCのブラウザで開きます。既存サーバーが4310番を使用中なら先に停止します。
2. ゲーム画面の「ChatGPTでログイン」を押し、表示された認証ページでコードを入力して本人のアカウントで承認します。
3. 元のゲーム画面に戻り「接続済み」を確認。難易度を選択し、マイク・カメラを許可してゲームを開始します。
4. 終了時は端末でCtrl+C。専用認証と一時写真を破棄するため、次回は再ログインします。

ビルド済みなら `npm run play:codex:start` で再起動できます。対応Codexバイナリは単体PoCと同じ版を自動探索します。旧ゲーム起動の `--browser-login` は廃止し、画面のデバイス認証を使います。単体 `poc:codex` の診断機能はそのままです。

## 経路と制限

| 処理 | 利用経路 |
| --- | --- |
| 写真認識・意図分類・相談・行動のゲーム判断 | ログイン本人のCodex枠 |
| GPT-Live音声・画像生成/検査・動画などのメディア | 既存サーバーのAPI設定 |
| 通常の `npm run dev` での起動 | 従来のAPI経路 |

Codexエラーや枠切れで運営APIに自動切替しません。端末の `Codex判断: completed / …ms` は1判断の処理時間で、音声を話し終えて返答が聞こえるまでの時間とは異なります。1操作で複数判断が発生する場合があります。JSON修復は既存の上限内で再試行されます。

既存の回数・同時実行・タイムアウト制限は維持します。Responses APIの `max_output_tokens` と同じ出力上限は、このApp Server経路では設定していません。全処理の無料化や、定額内の無制限実行を確認したものではありません。

## 手動確認

- タイトル画面からログインし、音声接続と会話ができる。
- 写真を送り、写真の特徴に沿った判断が返る。端末にCodex判断の完了が出る。
- 相談→行動→次の障害物まで連続して進められる。
- 判断待機中に終了し、その後に結果がゲームへ混入しない。
- Ctrl+C後に4310番が閉じ、再起動すると専用ログインを要求する。
- 通常のAPI起動も利用できる。

報告時は「モデル／操作内容／端末の判断時間／体感待ち時間／成功・失敗」を記録してください。認証コード・写真・キーは貼り付け不要です。

旧・端末認証版ではユーザーが写真送信→ギミッククリアと `Codex判断: completed / 9801ms` を確認済みです。新しい画面認証版での実ログインと実プレイは確認待ちです。
