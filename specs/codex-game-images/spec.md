# サブスクでの状況画像生成

2026-09-18: ユーザーは画像生成も本人のサブスク内で調査・実装する方針を選択。声は当初marinを選択したが、実接続で拒否されたため対応一覧にあるjuniperに修正。APIはgleamを維持する。

1. 既存の状況画像ジョブを再開し、ゲーム専用App Serverの組み込み画像生成を使う。APIキーへのfallbackなし。
2. 画像は既存の公開シーンプロンプトから生成。別のCodex判断スレッドで検査し、合格後のみ表示する。
3. 音声・ゲーム判断と画像生成は別スレッド。本人のplayIdに結び付く認証を使用し、任意RPCやファイルパスをブラウザに公開しない。
4. 上限・キャンセル・期限・再試行は既存SceneJobsに従う。上限到達や未対応時には失敗表示を残す。API生成へ切り替えない。
5. APIキー経路のモデル・声・生成処理を変更しない。動画と追加結末生成は今回対象外。
6. 自動テストと実アカウントの生成・音声確認を区別する。
