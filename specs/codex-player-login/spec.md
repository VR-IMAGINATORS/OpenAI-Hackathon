# プレイヤー画面からのCodexログイン

2026-09-18 ユーザーの実装依頼に基づく。既存ローカル試遊を拡張し、起動者の認証からプレイヤー単位の認証へ変更する。速度改善は対象外。

1. play:codexは認証なしでゲーム画面を配信。開始画面から本人がログインを開始し、OpenAIのデバイス認証ページとコードを表示する。
2. HttpOnlyの既存play_session Cookieを所有者とし、所有者ごとに独立プロセス・一時CODEX_HOMEを確保する。ブラウザへトークンを渡さず、認証コードも端末/アクセスログへ記録しない。
3. 状態は未接続/準備中/承認待ち/接続済み/失敗。接続済みのみ新規ゲームを開始でき、サーバーも検証する。再読込で状態復元、取消/ログアウト/期限切れを扱う。
4. 各playIdを認証済み所有者にサーバー内部で結び付ける。判断は必ずその所有者のCodexを使う。未認証・別セッション・失効はAPI fallbackしない。
5. プレイ中のアカウント交換は禁止。プレイ終了/期限/サーバー終了で専用プロセスと認証を破棄。待機だけの認証も期限と容量で制限する。
6. API版の通常起動を維持。GPT-Live/画像生成/動画は既存API課金であることを画面にも表示する。BYOK UI、外部公開、スマホ/同時多数プレイヤーの実運用は対象外。ローカル上でもCookieが異なれば認証を共有しない。
7. 認証分離・競合・取消・期限・API回帰は自動検証。実認証と実ゲームの成功はユーザー実機確認と分離する。
