# ゲーム画面からプレイヤー本人がログイン

既存プロセスをCtrl+Cで止め、Git Bashで次を実行します。

```bash
GAME_MODEL=gpt-5.6-luna npm run play:codex
```

1. `http://127.0.0.1:4310` を開く。起動時にはログインを求めません。
2. 日本語で試す場合はLanguageを日本語に変更。「ChatGPTでログイン」を押す。
3. 画面のコードを確認し、「OpenAIの認証ページを開く」を押す。
4. OpenAI側でプレイヤー本人のアカウントを選び、コードを入力して承認する。
5. ゲーム画面に戻る。「接続済み」になると難易度を選択できる。
6. 写真を送ってプレイ。端末の `Codex判断: completed / …ms / play=…` で判断経路を確認できる。

パスワードはOpenAIの画面だけに入力します。ゲーム側はブラウザにアクセストークンを返しません。認証コードはゲーム画面だけに表示し、端末には記録しません。

ゲームの終了処理が完了すると専用認証を破棄します。新しく遊ぶ場合は再ログインしてください。未プレイの認証は10分、認証待機は約3分で失効します。開始前なら「ログアウト / 別のアカウント」で接続を解除できます。

同じブラウザプロファイルのタブは同じプレイヤーセッションです。別のプレイヤーとして分離を試す場合はシークレットウィンドウまたは別ブラウザを使います。現在の起動設定は同時1接続なので、先のプレイヤーを終了/ログアウトしてから交代します。別ブラウザが先の認証を引き継ぐことはありません。

ゲーム判断は本人のCodex利用枠、GPT-Live・画像生成/検査・動画は引き続き運営APIです。通常の `npm run dev` は従来のAPI版。プレイヤーのAPIキー入力UIは未実装です。

## エラー時

- 接続失敗: 画面で再ログイン。デバイス認証がアカウントで許可されているか、Codex利用枠と指定モデルを確認。
- バイナリの問題を疑う場合: `npm run poc:codex -- --check`。これは診断用で、起動の前提条件ではありません。
- 別の接続が使用中: 先のブラウザでログアウトまたはプレイ終了。失われた認証待機は約3分、接続済み待機は10分で解放。
- 終了処理の失敗: サーバーをCtrl+Cで終了して再起動。確認できない接続を再利用しません。

## 手動確認チェック

- [ ] ターミナルでログインせず、ゲーム画面が表示される。
- [ ] 未ログインでは開始できず、コードを承認すると開始できる。
- [ ] 写真送信からギミッククリアまで進み、Codex判断ログが出る。
- [ ] ログアウト後、別のプレイヤーが自身のアカウントで接続できる。
- [ ] 別ブラウザでは、他者のコード/接続済み状態が表示されない。
- [ ] プレイ終了後、新規プレイには再ログインが必要。

公式のデバイス認証フローを利用しています: [Codex App Server](https://developers.openai.com/ja-JP/docs/app-server)。現段階はローカル試遊用で、公開URLへのデプロイは行っていません。
