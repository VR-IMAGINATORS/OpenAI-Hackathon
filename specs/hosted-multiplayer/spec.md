# AWS公開と複数人試遊

2026-09-14追記: 開始画面の難易度選択とプレイ作成時の上限固定は [difficulty-selection/spec.md](../difficulty-selection/spec.md) を参照。

## 1. 目的と優先順位
審査員・知人・開発メンバーが公開URLから、スマホを中心に音声と写真の脱出ゲームを体験できるようにする。GitHubは実装確認用であり、審査員のローカル起動を要件にしない。
根拠は proposal/server-structure-change/server-structure-change.md と .specworkflow/discussions/2026-09-12-hosted-multiplayer.md。本仕様はweb-foundation/mobile-playtestの配布・認証・単一プレイの前提を更新する。ゲームルール、シナリオ、GPT-Live/Responsesの役割、導入画像/会話の内容は維持する。

## 2. 要件
- R01: Web配信・ゲーム・AI通信を単一アプリサーバーへ統合。独立relay起動不要。APIキーはサーバーのみ。
- R02: 共通合言葉で参加。アカウント作成・個別招待不要。認証だけでは有料APIやプレイ枠を使わない。
- R03: プレイヤーごとにゲーム/写真/在庫/音声/認識/時計を分離。同時上限は環境ごと初期5、設定可能。満員は自動待機列に入れず再試行を案内。
- R04: 音声接続・体験開始ボタンで枠を確保し、チュートリアルも占有に含む。マイク拒否・接続未完了を無期限に保持しない。
- R05: 同じブラウザのリロード/再接続は同一プレイへ復帰。重複タブで別枠・二重音声を作らない。異なるブラウザへの引継ぎは対象外。
- R06: 切断後最大60秒で失効。体験全体は枠確保から実時間10分まで。再接続・リロードで延長しない。既存のゲーム時計/待機上限で先に終了することはある。
- R07: 状態はメモリのみ。再起動/デプロイでは失われ、理由を案内して最初から。終了・期限切れで写真/会話を破棄、音声を終了。終了未確認の有料接続は安全確認まで別枠として予約を維持する。
- R08: ローカルは1つのアプリサーバーとtunnelでスマホから試遊。ターミナルに公開URLとQRを出す。QRは共通URLのみ、秘密や一回招待を含めない。
- R09: AWSはLightsail Containers Micro、scale=1。標準HTTPS URL。必要に応じNanoへ縮小するが、同時5人の負荷測定前には確定しない。
- R10: 最初は開発1環境、審査前に確認済みバージョンの別環境を用意。各環境の合言葉・セッション・上限・秘密設定を独立させる。
- R11: main更新を契機に検証後開発環境を自動デプロイ。審査用は明示バージョンの手動デプロイ。更新中の中断は許容。期間後はAWSリソースを削除する手順を用意。
- R12: ログは開始終了・エラー分類・処理時間・API回数等の運用情報のみ。写真/会話/プロンプト本文/SDP/認証情報をログ・永続ストレージに出さない。
- R13: モデル・要求サイズ・API回数・同時実行制限を統合後も維持。5人分に調整。ブラウザは任意プロンプト/任意上流URL/任意API要求を送れない。
- R14: 自動テスト、AWS疎通、実スマホ、同時5人負荷、実API終了を別々に記録。未実施を成功扱いしない。

## 3. 画面とフロー
URL→合言葉→体験開始（ブラウザのマイク許可）→枠確保とLive接続→既存の導入→明示的な本編開始→写真/相談/認識確認/明示実行→結果→再プレイ。
満員、合言葉不正、接続待ち、復帰可能、別タブ使用中、期限切れ、更新による消失、API利用上限を区別した短い日本語案内を出す。撮影中に接続が保たれている場合は切断扱いにしない。音声再生制限はユーザーの再開操作で解除する。
結果画面表示のための短い終了猶予は体験10分を超えない。再プレイはユーザー操作で新しいプレイを作る。

## 4. データと失敗
認証cookieとサーバー所有権でプレイを特定する。他人のIDだけで状態取得/変更不可。非同期処理の遅延結果はplay ID/generation/revisionで検証する。正常終了、利用上限、通信失効、更新消失を区別する。Live作成結果不明/終了未確認は無制限の再作成にせず運営向け障害として扱う。
共通合言葉は個人の識別や人数の厳密な証明ではない。制限はブラウザ/プレイと環境全体で行う。再起動でメモリ上の利用回数は戻るため、金額の絶対上限を保証しない。

## 5. 対象外
ゲームのルール変更、プロンプト再設計、動的画像/動画/緊迫イベント、ユーザーアカウント、永続的な途中再開、待機列、水平スケール、プレイ内容の分析保存、独自ドメイン。

## 6. 受け入れ条件
5つの独立ブラウザが混線せずプレイし、6人目はAPIを使わず満員。1人終了で再参加可能。再読み込みは同じ枠/状態、二重操作で二重課金要求を起動しない。切断/最大寿命/再起動の復帰・失効が上記どおり。ローカル1サーバー＋QRとAWS標準URLの双方で音声・撮影を確認。main自動/審査手動の両配信を確認し秘密非露出を検証する。

## 7. 未実施の確認
AWSアカウント/IAM/OIDC・OpenAI利用権限/同時利用上限の初期設定、Lightsail実負荷・更新時挙動、スマホ端末別の撮影復帰は実装後の公開ゲート。これらの値や実測を推測で埋めない。
