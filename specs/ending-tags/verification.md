# エンディングタグの確認記録

2026-09-14 / `codex/ending-tags`。ローカル実装。共有作業ディレクトリに同時進行の動画MP4関連変更も存在するため、全体テスト件数は検証時の作業ツリーに対する件数。

## 実装

- 固定40タグ、日英表示名、AI用判定条件。
- 既存の結末生成1回でタグと短文を返す。全確定行動を対象にし、タグの出典は映像用の直近2行動に限定しない。
- 文章を画像制作前に保存。storyStatusを公開し、動画未完成・無効でも文章を自動表示。
- 動画無効・素材なし・動画予算不足では文章のみ生成。Responses予算・1回制限を継承し、mockと中断は実生成なし。
- 文章のみの実行枠を動画枠から分離。画像・動画失敗でも保存済み文章を維持。
