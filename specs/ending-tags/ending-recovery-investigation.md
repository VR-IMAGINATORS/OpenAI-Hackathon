# 結末文の失敗調査（2026-09-15）

## 今回のログから分かること

Play ID `1348b791-740f-4de2-9898-bca7cf4f7863` は解除0個・行動1回・失敗1回。画像とログの `ENDING_STORY_INVALID_EVIDENCE` は、タグ判定前の手がかり抽出で、出典IDが見つからないか引用が原文の連続部分と一致しなかったことを示す。48 KiB超の記録だけが抽出へ進むため、行動1回でも会話が長ければ発生する。旧ログには元の引用がないので、言い換え・句読点変更・音声断片の連結・出典取り違えのどれだったかは断定できない。

同時の `request_failed / PLAY_EXPIRED` には経路や相関IDがなく、この抽出失敗と同じ原因とは判定できない。終了後の通常操作は拒否されるが、終了前に予約済みの結末生成は専用の期限で継続する。AI利用制限テストと認証付きHTTPテストで、プレイ終了・ランタイム破棄後の文章保持と動画完成を確認した。

## 失敗経路と修正

| 失敗経路 | 対応 |
| --- | --- |
| 抽出の引用不一致・架空ID・壊れたJSON・不正形式・未完了 | 不正な抽出を丸ごと破棄。元の提示記録だけを最大32 KiBまで選んで文章生成を続ける。 |
| 単一記録が96 KiB超、または分割が6チャンク超 | 抽出送信前に元記録からの生成へ移る。大きすぎる任意の記録を省略し、確定行動・結果は維持。 |
| 抽出が長引いて文章側60秒を消費 | 抽出全体の専用期限15秒で中止。通信の中止完了を待ち、残り時間で文章生成。 |
| 複数チャンクの日本語引用の合計が128 KiB超 | 合計を最大48 KiBに制限し、入力全体にも修正指示の余裕を確保。 |
| 全行動に同じ状態一覧が入り入力上限超過 | 必要時だけ各行動の状態を変更箇所に圧縮。行動、道具、成否、実際の変化、最終状態を維持。 |
| 1行動しかないのに反復使用・学習などのタグを選択 | 成立しない候補を事前除外。タグ検証で失敗した修正要求はtag=nullに制約し、本文も書き直す。 |
| 文字起こし待機中の期限切れ・ジョブキャンセル | storyErrorCodeにも記録し、動画エラーと分けて追跡できるようにする。 |

任意の記録を省略した場合は `evidenceIncomplete=true` を文章と映像の両方へ渡す。記録を文の途中で切らず、欠けた伏線は作らない。保存済みの原記録は変更しない。文章は引き続き実AIが生成・検証したものだけを公開する。

追加ログ：`ending_failed_extraction` は抽出からの回復開始で、文章の最終失敗ではない。`quoteMismatchCount` は原文不一致件数、`invalidSourceCount` は出典不一致件数。`evidenceRecordCount` と `evidenceBytes` は入力規模。ログには本文・写真・認証情報・不正な出力値を含めない。最終的な成否は `storyStatus` と `ending_failed_story` で確認する。

通信障害・API認証失敗・拒否・共通予算枯渇・全体期限切れ・キャンセルは引き続き明示的な失敗になる。これらを成功扱いにせず、課金回数や全体制限も増やさない。最大2回の文章応答がともに不正な場合も失敗を保持する。
