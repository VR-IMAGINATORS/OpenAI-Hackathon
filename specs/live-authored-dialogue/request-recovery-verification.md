# 受領済み依頼の回復

2026-09-16 / ユーザー指示により `feature/shibuya/game-polish` に実装。

## 動作

写真と使用指示を受領した後の判定エラーを、ユーザーの説明不足として返していた。行動予約に保持した入力をそのまま使い、許可した技術的エラーは内部で一度修復する。回復すれば結果だけを一度通知する。

回復しきれない場合は、依頼を保持して処理を終了する。Liveには `request_unavailable`、保持の有無、`requiresRestatement: false` を渡す。「もう一度やって」は分類モデルが `retry_request` に分類し、サーバーが元の使用方法と道具の参照を復元する。モデルに再開IDや代わりの使い方を生成させない。中止は `cancel_request` で破棄する。

再試行のたびに相づちを送らず、通常の「試したが失敗した」という結果をやり直さない。内部修復は同じ具現化IDを使い、成功済みの結果を再判定しない。回復後の明示的な再開は新規発話の根拠を必要とし、以前の発話や委譲の再送では再実行しない。
