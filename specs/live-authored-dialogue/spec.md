# Liveが会話を組み立てる

Status: user-requested / approved in conversation (2026-09-15)

## 背景と範囲

別モデルの完成台詞をLiveへ渡す構成を改め、発話の言葉選びと会話のつながりをLiveに集約する。ユーザーの「そうしよう。実装してみて」に基づく実装。日本語の自然さ・誤読・意味的な重複の改善は実音声で検証し、自動テストだけで保証しない。

## 受け入れ条件

- L1: 行動結果の追加Responses台詞生成を本編から外す。Liveには確定後の公開結果と現在状況だけを渡し、秘密の判定理由・ギミックを渡さない。
- L2: 相談の裏側モデルは回答に必要な公開事実・不確実性・必要な質問を返す。相づちや完成台詞を書かせない。Liveが会話履歴に合わせて表現する。
- L3: 雑談はLiveが返答を考える。既存の本編会話30クレジットを維持するため受付・分類・精算はサーバーに残す。雑談受付では回答原稿を生成しない。ゲーム質問、訂正、実行を雑談の扱いで迂回しない。
- L4: 一つの通知を分割して複数回発話させない。長い資料は通知IDと部分番号付きの内部情報として送り、最後に一度だけ発話を依頼する。不完全な通知には発話依頼を送らない。同一イベント再送・同じユーザー証拠の再処理では二重発話依頼・二重精算をしない。
- L5: Liveは既に話した相づち・結果を繰り返さず、新しい情報を自然につなげる。ユーザーからの聞き直しには応じる。確定前の成功や新しい世界設定を生成しない。時間警告・危険確認・中断・最後の音声待機・再接続を維持する。
- L6: モデル、認証、写真、クレジット単価、ゲーム判定・終了条件を維持する。実APIキーや音声をログへ追加しない。

## 受領済み依頼の回復（2026-09-16の会話承認）

ユーザーの説明は済んでいる。内部の不調を説明不足として扱わず、サーバーが受け取った道具・使い方を使って回復する。行動の技術的失敗について、以前の再依頼案内を以下で更新する。

- R1: 元の試行を含め判定は最大2回。一時的な上流5xx、回答の途中切れ・形式不備、状態・在庫・完了条件などの検証不備は同じ予約・写真・具現化IDで一度修復する。修復理由は固定コードだけを渡す。通常の物理的な失敗、拒否、利用上限、失効は自動再実行しない。
- R2: 修復可能性の検証は状態変更や創造性の抽選より前に行う。確定結果は再利用し、行動・道具・通知・クレジットを重複確定しない。訂正判定中は再試行も止め、中止後の古い回答を反映しない。
- R3: 回復しきれなければ未完了の依頼をプレイのメモリ内に保持し、処理の不調と伝える。再説明・再送を求めず、継続していない処理を「待って」でごまかさない。以後の「もう一度やって」は新しい発話の根拠と実Live委譲を通し、保存した道具・使い方で再開できる。無言や相づちだけでは再開しない。
- R4: 明示的な中止、使い方の変更、認識訂正、新しい写真、操作権・ゲーム状態の失効で古い依頼を再開しない。通常の相談や相づちでは保持を続ける。再開する依頼のIDはサーバーが設定し、分類モデルに書き換えさせない。
- R5: 失敗時の返金を維持する。音声で指示した行動は完了時に会話30クレジットを一度精算する。写真からの自動行動が失敗して写真代を返金した場合、再開時は元の写真枚数×150だけを予約し、完了時に精算する。再開を依頼する音声に会話30を追加しない。実APIの追加呼出しは既存の利用上限に従う。

実装・検証の詳細は[依頼回復の検証記録](request-recovery-verification.md)。サーバー再起動を越える永続化と、写真認識前・意図分類中の全エラーの自動修復は今回の範囲外。

### エラー通知へ至る頻度の削減（2026-09-16追記）

ユーザーから、再開できることに加え、そもそも内部エラーを返す頻度の削減が必要と指摘された。上記実装に続き、写真認識、写真の反応判断、意図分類、相談・制御の構造化応答にも、状態反映前の通信・形式エラーの内部修復を追加する。各呼出しは最大2回、行動判定はGameSessionの2回枠に一本化する。推論を含む出力枠は通常2,048・修復4,096とし、ゲーム内部専用の上限を適用する。短時間の同時実行枠不足は最大5秒・待機20件まで待つ。回数上限や失効を迂回しない。詳細と限界は[内部エラー経路の点検](systemic-failure-audit.md)。

## 検証

公開情報の限定、台詞生成呼出しゼロ、雑談受付、相談の重複防止、分割通知の一回発話と不完全送信、再接続、時間警告と最後の音声を自動検証。npm run check / npm test / npm run build。実音声では同じ質問・写真・聞き直しで自然さ、誤読、二重発話を確認する。
