## 実音声での確認（未実施）

既存の実AI設定でサーバーを再起動し、新しいプレイで試す。スマホは `npm run play:mobile`。進行中のプレイには開始時の設定が残る。

1. 接続確認→導入。呼びかけが重複せず、ユーザーの返事後に説明する。
2. 「応援して」「ちょっと緊張する」など雑談。返答が自然につながり、画面の残高は一往復20減る。
3. 「今どういう状況？」→実行指示。同じ受付・状況の二度言いがない。成否は確定後に伝わる。
4. 写真の自動行動。受付と結果の同じ説明を繰り返さず、結果と新しい状況を一つの返答で伝える。
5. 「もう一度説明して」。重複禁止のために返答を拒まない。長い説明で文節ごとの不自然な間やJSON・IDの読み上げがない。
6. 「待って」「使い方を変えて」と割り込む。取り消した古い結果を話さず、具体的なリスク確認も省略しない。
7. 時間警告→終了。通常警告が会話を遮らず、最終結果を話し終えて通話が閉じる。
8. 誤読した漢字・固有名詞を記録し、変更前と同じ内容で比較する。

音声の自然さ、漢字の読み、モデルによる意味的な反復、実API上の分割資料の扱い、実スマホ撮影は自動テストの成功に含まない。マルチレビュー・push・デプロイは実施していない。
