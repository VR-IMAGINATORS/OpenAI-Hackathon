# サブスクだけで遊ぶゲーム接続

2026-09-18の合意: Live接続PoCを成立と扱い、プレイヤー認証で判断・音声をゲームへ接続する。正確なモデルIDや課金枠の詳細は別の確認事項。

1. `play:codex` はローカル同時1プレイ。ゲーム画面から本人がログインし、同じ専用プロセスで写真判断とLiveを利用する。
2. サブスク経路はAPIキーを使わず、API経路へfallbackしない。従来のAPI構成は通常起動で維持する。
3. Live v3のmodelを指定しない。ゲームの公開指示は開始時のprompt、声はjuniperで指定する。接続後のinstructions変更は禁止。Codex専用変換層で既存の委譲・文字起こし・確定事実のoutboxを再利用する。
4. 写真送信、ギミック判断、残り時間、勝敗、切断・再接続・終了を既存ゲームに接続する。任意RPCや秘密認証をブラウザへ公開しない。
5. 状況画像はspecs/codex-game-imagesに従い本人の組み込み画像生成と検査で表示する。エンディング動画・追加の結末文章生成は省略し、開始画面に示す。公開APIは呼ばない。
6. 所有者・playId・controller epochと予算は既存サーバーの管理を維持。終了確認が不明なら成功と偽らず、専用プロセス・認証を破棄する。
7. 合格条件: キーなし構成でログイン→音声会話→写真→判断→ギミッククリア→終了。自動テストは模擬で実音声成功と区別する。
