## Files / integration

`packages/server/image-service.ts`, `packages/server/ai-service.ts`, `packages/server/ai-config.ts`, `packages/server/openai.ts`, `apps/server/scene-jobs.ts`, `tests/core-media.test.ts`。

SceneJobs.enqueueはplayId/messageId/ScenarioSnapshot/facts/situationとready/failed/stage callbackを受ける。deadlineはmonotonic時刻。生成物はready callbackだけへ渡し、ResultStoreの所有権・期限照合を経て公開する。画像完了に最新gameVersion一致を要求せず、元messageのみ更新する。

ResultStore evictionはforgetPlay、手動終了/接続失効/絶対期限はcancelPlay(id,true)、drain/shutdownはcancelAllを呼ぶ。AiService.snapshot.mediaBusyを運用remainingに含める。公開/HTTPとの接続は主担当のP3/P5統合で実装する。

## Remaining limits

途中進捗率は取得せずstatusだけを表示する。abortはHTTP読取停止を意味し、provider側生成・課金停止の保証ではない。予算と結果はメモリのみで再起動時にリセット。待機上限やIPMにより画像が期限内に届かない場合は指定失敗枠となり、ゲームは継続する。
