# P2 — 本編の音声意図判定と一度だけの行動確定

Status: runtime integrated; automated verification passed; real Live verification pending (2026-09-13)

## 実装

- 本編の音声transcriptと委譲をHTTP 202で受け付け、会話台帳と単一分類ワーカーへ渡す。相談は実行せず、実行可能な指示だけを予約する。
- 写真認識後に用途を質問。実行指示には短い行動開始通知を返し、復唱確認と実行ボタンを挟まず判定する。
- 同じ発言の再利用、古いcontext/game/action/controllerの判断、重複委譲を防ぐ。判定中・曖昧な後着音声は次の行動根拠へ自動転用しない。
- 部分進展と在庫変更を全件検証してから一度だけ確定。技術失敗では行動数を消費しない。
- outboxを500ms間隔で取得し、送信後にackする。同一event_idの再送を抑止し、内部のseq/messageIdはLiveへ渡さない。ackは再生完了を意味しない。
- core終端ではLive generationを維持し、最後の通知に最大12秒の猶予を設ける。
- 通常のv2本編はautomaticActionsを使う。旧v1経路の回帰テストはscenarioCatalogを明示的に無効化して維持する。
