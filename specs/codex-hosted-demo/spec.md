# ChatGPT認証で遊ぶ公開技術デモ

2026-09-18。ユーザーはコミット・develop向けPR・developからリリースブランチを切ったデプロイを依頼し、公開URLでも本人のChatGPTアカウントで遊べることを明示した。

1. 既存LightsailのHTTPS URLで、本人のデバイス認証後に音声・写真判断・状況画像生成を実行する。Codex経路はAPIキーへフォールバックしない。
2. Cookie所有者ごとに専用のCodexプロセスと一時認証領域を作る。コードと認証状態を他者に返さず、アクセストークンをブラウザ/ログ/永続ボリュームへ出さない。
3. 正常終了後10分は同じブラウザで認証を保持。ログアウト・失効・異常・サーバー終了で破棄する。公開デモは初期同時2認証を上限とし、満杯は明示拒否する。
4. API版はAI_PROVIDER=apiで維持。公開デモはAI_PROVIDER=codex、APIキー・動画キーをコンテナに渡さない。動画と追加結末生成は既存Codex仕様どおり省略。
5. Linux amd64向け公式Codex 0.154.0-alpha.6.2を完全性検証付きで固定し、起動できない環境を配信しない。既存のmain配信・drain・SHA一致確認を利用する。
6. Linuxでの起動/契約検証と実アカウント音声成功を区別する。ログインは本人が行い、公開後の実音声・画像品質は手動確認とする。
