# Codex認証によるGPT-Live音声の調査・接続PoC

2026-09-18、ユーザー依頼「GPT Live APIが使えるかの調査および、可能そうであれば実装」に基づく。

1. 目的はGPT-Live音声のサブスク経由接続可否の実証。従来Realtimeモデルへの置換はしない。
2. 固定版App Serverの実験的thread/realtime/startで、version=v3、WebRTCを明示する独立したローカル音声ページを追加する。実機でsession.model指定が拒否されたため、音声モデルは指定せずCodex標準で接続する。報告モデルを観測してGPT-Liveか検証し、未報告なら未確認、別モデルが報告されたら停止する。APIキーを読み込まず、通常ゲームも変更しない。
3. 画面で本人のデバイスログイン。専用Cookieと専用プロセス/一時認証を使用。他ブラウザの認証は使わない。
4. マイク許可・SDP交換・受信音声再生・固定テキスト送信への音声反応・停止を試す。appendSpeechで送信文の逐語読み上げは保証しない。開始受理と実音声成功、要求モデルと観測モデルを区別する。任意RPC/モデル/プロンプトはHTTPに公開しない。
5. 音声開始要求から最大60秒、ブラウザstatus通信途絶20秒で停止。ログイン待機3分、開始前待機5分で破棄。停止通知確認とプロセス破棄を区別し、不明な場合は成功扱いしない。
6. 音声/文字起こし/SDP/認証コードを保存・ログ出力しない。画面には安全な状態・イベント種別・モデル名だけを表示する。
7. 自動検証は模擬上流と明記。実認証・会話・枠消費の実測が得られるまでゲーム音声のサブスク化を完了扱いしない。
