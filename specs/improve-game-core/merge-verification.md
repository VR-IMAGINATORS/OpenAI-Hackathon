# game-polish と improve-game-core の統合

日付: 2026-09-15

## 対象

- 反映先: `feature/shibuya/game-polish`、統合前 `4a6971d`。
- 取り込み元: `origin/codex/improve-game-core` として取得した `f1514b0`。
- ユーザー指示: 取り込み元の実装意図を保ち、既存の改善も活かして競合を解消する。

## 統合判断

- 取り込み元の `GameHarness` をゲーム判断の共通実装として採用。Webとテキスト模擬の調査・情報開示・写真・行動・精算を分岐させない。
- 既存のLive発話改善を共通ハーネスへ移設。行動結果の追加台詞生成を除去し、公開事実からLiveが返答を組み立てる。写真自動行動の受付台詞と、相談直前の重複した現況送信を戻さない。
- テキスト模擬には同じ公開結果を文章で返す。Liveの通知JSONをプレイヤーの会話履歴へ混入させない。雑談は受付のみで、模擬用の回答原稿を新たに生成しない。
- 調査の段階的な情報開示、仮説・提案の積極性設定、補完値の固定、古い応答からの知識更新防止を維持。調査回答モデルの指示を公開資料の生成に揃える。
- 長い通知の分割後も発話依頼は一度だけ。同一通知IDと未完通知の扱い、最後の音声再生待機を維持。
- 拡充シナリオ用画像にも確定した使い方・道具状態・公開結果を渡す。非公開の内部状態値・検査の説明は生成へ渡さない。既存シナリオの行動描写とエンディング映像の改善を維持。
- 拡充CLI・予算管理・評価・採用・共有試遊コマンドを取り込む。廃止した台詞生成呼び出しを前提とした模擬テストを更新し、判定API失敗時の未完了・使用量記録も検証する。
