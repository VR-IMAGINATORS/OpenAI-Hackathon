## 前提

- 課金なしの `npm run check` / `npm test` / `npm run build` を実行する。
- 実APIの費用上限を実行前に決める。初回は3プレイで止め、使用量と残り6プレイの予測を見て判断する。
- 3プレイだけ、mockだけ、未完了の候補を「live評価済み採用」と呼ばない。
- 人間が採用した固定シナリオを明示的に選んで起動する。AWS反映は本作業に含めない。
- 運営の秘密はサーバー環境変数または `.env.local` で管理する。ルート `.env` は読まない。
