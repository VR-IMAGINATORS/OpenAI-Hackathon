# AI利用クレジット

Status: user-requested / approved in conversation (2026-09-15)

## 要件

- C1: 写真送信回数上限を廃止し、サーバー管理の残りクレジットへ置換する。会話1往復30、写真1枚150（2枚300）。音声による指示・手持ちの再利用は会話30だけ。写真に続く説明・自動行動に追加料金を設けない。
- C2: スタンダードProプラン1000・300秒、ハードPlusプラン750・240秒、ヘル無料プラン500・180秒。内部難易度IDは維持する。再接続・再読込で残高を戻さない。
- C3: 本編の相談・雑談をサーバーが受け付けた応答単位で精算する。文字起こし断片、内部AIの追加呼出し、同一要求の再送は追加消費しない。接続確認・導入、自動の状況説明、画像・動画生成、撮影・プレビュー、システム失敗、誤認識の訂正は無料。
  - [Liveによる発話生成](../live-authored-dialogue/spec.md)では雑談の台詞をLiveが考える。サーバーの雑談受付を `responseKind: social` として区別し、受付・通知・精算の順序と30クレジットは維持する。長い相談資料の送信が途中で失敗した場合は発話依頼を送らず予約を取り消す。
- C4: 処理前に費用を予約して並行要求による使い越しを防ぐ。足りない写真は拒否し、残高で可能な会話を続けられる。残高30未満では新規要求を受けず、受理済みの最後の応答・行動を確定後に終了する。その行動で脱出すれば勝利を優先。時間制限・中断は現行のまま。
- C5: 本編には残りクレジットを表示。下部の会話・写真の料金案内と消費時の通知は表示しない。残り20%以下は「ご利用可能クレジットが残りわずかです」、枯渇時は「クレジットを使い切りました。」。英語にも対応する。
  - クレジットの残高・警告は画面で案内する。Liveに残高を配信せず、Liveや相談回答から残高・料金・不足を自発的に音声案内しない。既存の残り時間の音声警告は維持する。
- C6: 枯渇は既存の敗北処理から既存リザルトへ接続する。解除数による評価・リザルトUI・内訳・エンディング生成仕様は変更しない。終了理由だけは時間切れと区別し、架空の時間切れを記録しない。
- C7: 現在の feature/shibuya/game-polish 上で実装・検証・コミットする。pushや公開は含まない。実AI・実音声・実機の未検証を自動テスト成功と混同しない。

## 検証

難易度の固定、枚数課金、会話の断片/重複/救済経路、訂正・失敗時の非消費、並行処理、残高不足、枯渇終了、最後の一手の勝利、時間切れ、再接続と既存リザルトの回帰を自動検証する。標準JSON・型・ビルドも確認する。

## 正本の更新

本仕様は difficulty-selection / photo-send-limit / game-core の写真回数・終了条件を置換する。GPT-Live、写真からの自動行動、3障害と既存の物語・結果表示を引き継ぐ。
