## ハッカソンの参加
本プロジェクトは、OpenAIが主催するハッカソンに参加し、開発をしているゲームとなります。
お題は、「AIネイティブゲームをつくる」で、書かれている要件は以下です。

​生成AIがゲーム体験の中核を担う、実際に遊べるゲームプロトタイプを開発してください。キャラクターやストーリー、ルール、ゲームメカニクスが、プレイヤーの行動や状況に応じて変化するような体験を想定しています。

​たとえば：
- ​プレイヤーとのやり取りによって変化・成長するキャラクター
- ​プレイに応じてその場で生成される会話やストーリー
- ​プレイヤーの意思決定に応じて展開が変わるゲームプレイ
- ​AIによって生成・変化する環境やビジュアル
- ​ゲーム体験そのものに影響を与えるリアルタイムAI推論
​ポイントはひとつ。「AIがなければ、このゲーム体験は成立しないか？」です。

## ​審査基準
- ​OpenAIテクノロジーの効果的な活用：30%
- ​独創性：25%
- ​プレイアビリティまたは実用性：25%
- ​実装力・完成度：20%

​各提出物には、動作するデモ、プロジェクトの簡単な説明、応募部門、OpenAIのテクノロジーをどのように活用したかの説明を含める必要があります。
​使用するOpenAI製品の数は評価対象ではありません。プロジェクトに最適なテクノロジーを、効果的に活用しているかを重視します。
​第三者が権利を有するキャラクター、アセット、商標、音楽などを、許可なく使用することはできません。
​参加にあたっては、こちらのルール (URL) および規約（URL) をよく読み、内容をご確認ください。

## 企画案
1．未来からAIの電話がかかってくる
　→ 〇日後、君は誰かに殺されそうになっている。
　　監禁されているので、
　　君を助けるためにキーアイテムを送って欲しい、と言われる。
2．現代の写真を送ると、AIから未来の画像が送られてくる
　→ 脱出ゲームのキーアイテムの写真を送って欲しいと言われる
　　例）ハサミで縄を斬る。ライターで何かを燃やす　とか
3．写真とセットで会話のテキストも送る
　→ 例）ビンの画像を送って、「コレを割って何とかして」を一言添える
4．写真を送れる回数と枚数
　→ 同時に2枚まで×4回　でストーリー終了
5．写真とテキスト情報から、結果動画を生成
　　→15～30秒くらいの動画
6．ハッピーエンドか否かで、スコアリングされてゲームエンド
　→ 写真、テキスト、動画から、ストーリー自体をAIが創作する
7.　FireBaseに各種APIキーを格納する
　→ 今回用のAPIキーを作成する

▼ UIイメージ
- 通話中の画面がベースとなる
　→ 写真の送信/受信は、LINEのようにポップアップするイメージ （編集済み）
