# ゲームループAIのブラッシュアップ
ゲーム体験をより、手触りのいいものにするためにブラッシュアップしたいです。

## 課題
現在感じている課題は、進行役AIがメタ発言（行動は消費していません、など）をしてしまったり、依頼したつもりでもそれを流されてしまったりすることがあり、それにより、実際の人間とやり取りしていたら感じないストレスを感じることがあります。

これをより自然に、本当に人間とやり取りしているような体感にしたい、というのが現在考えている課題感です。

## 方針
ゲーム進行は、まさにハーネスの領域であり、またLive APIの委譲システムおよび同機能により状況を注入できることがこのゲームを面白くするための肝だと考えています。
そこでこのハーネスをより強化することを考えています。

具体的には、Live APIへの指示文の注入の調整、ユーザの発話に的確に答えるための指示、委譲時に適切に応答する機能の拡充（※1）、行動回数などの状況管理、時間が来た際のユーザへのアテンションの調整（※2）、指示に対しての柔軟性の向上（※3）。

※1 ... 現状ではストーリーがやや手薄なため、「監禁犯がいる」ということはセリフにありつつ、「何人いるか、どんな服装か」などの情報がありません。しかし、ゆくゆくは設定を増やす想定なので、そうした裏設定を参照し、それを使って適切に応答できるようにしたいです。また、ある程度詳細なストーリーを用意する想定なので、それを元に、仮にそこに人間がいたら推測しそうなことも発話するようにしたいです。（例えば、人数が完全に把握できないが、足音が複数していることから複数人いそうだ、などを返す）

※2 ... 現状、制限時間が来た際にそれを伝えるように指示するようになっていますが、指示が強すぎるのか、AIの発話が物っと切れて「どうする？　これをどうつｋ ... 制限時間1分切ったよ！」みたいになってしまうのを防ぎたいです。

※3 ... 適当な指示でもしっかりと考えて結論を出してもらいたいです。例えば、鉄の閂がある、という場合に、チームメンバーが「溶岩で溶かして」と送ったら失敗した、というのですが、ある程度ユニークなものも通るようにしたいです。ただし、このあたりはガバガバだとなんでも通ってしまうリスクもあるため、どの程度まで許すかは設定ファイルで指定できるようにしたいです。
