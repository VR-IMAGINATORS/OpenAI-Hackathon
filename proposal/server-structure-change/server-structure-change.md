# 構造変更
現状の、リレーサーバを経由する方針を変えます。

まず、勘違いしていたのが、今回はWebアプリのため、提供する方法をAWSで公開する前提にすればそもそもAPIキーが漏れることはありません。
また、審査員が自分でサーバを立てて確認することはなく、提供資料に書かれているURLにアクセスして体験する、という流れが自然です。

審査員に渡すリポジトリ情報は、あくまで実装内容や実装力などを測るためのものであり、審査員が自分で起動する前提ではありません。

## 改修方針
前述の通り、APIキー隠蔽に気を使わなくてよくなったため、AWSにすべてをホストしてWebアプリとして公開するように調整します。
開発中はローカルサーバひとつ立ち上げて、tunnelによってアクセスする方針は変わりませんが、開発状況をAWSにホストして開発メンバーが手軽に体験できる状況を作りたいと考えています。

また、開発期間中、知りたいに体験してもらうなども考えたいため、それにはインターネット上に公開されている必要があります。
セキュリティ観点で言えば、現状の合言葉くらいの仕組みでOKです。
公開URLも知人にしか送信しませんし、開発期間、審査期間が過ぎたらサーバを閉じる予定のためです。
